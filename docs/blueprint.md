# **App Name**: Rota Segura Mobile

## Core Features:

- Relato de Incidentes em Tempo Real: Permite que os usuários relatem incidentes em tempo real.
- Mapas Integrados: Mostra os incidentes relatados em um mapa dentro do aplicativo.
- Atualizações em Tempo Real: Fornece atualizações em tempo real sobre incidentes usando o Firestore.
- Autenticação de Usuário: Autenticação segura de usuário via Firebase Auth.
- Categorização de Incidentes: Categoriza incidentes (por exemplo, trânsito, acidentes, perigos).
- Níveis de Severidade: Rotula o nível de severidade de cada incidente para melhorar a percepção situacional do usuário.
- Sumarização Automatizada de Incidentes: Ferramenta de IA para fornecer um resumo do relatório de incidentes para revisão rápida.
- Acesso ao Sistema: Permite o acesso ao sistema com diferentes perfis.
- Painel de Controle (Dashboard): Exibe uma visão geral da operação com cards informativos e status dos motoristas.
- Gerenciamento (Cadastros): Permite administrar informações do sistema (Escolas, Pais, Alunos, Motoristas, Veículos e Rotas).
- Gestão Financeira: Controla as finanças da frota com faturamento mensal, cobrança avulsa e controle de pagamentos.
- Mensagens: Comunica-se diretamente com os pais através de uma interface de chat.
- Otimização de Rota com IA: Utiliza a Inteligência Artificial para criar rotas mais eficientes, considerando as condições de trânsito.
- Plano de Rota e Controle de Embarque: Permite ao motorista visualizar a lista de alunos (paradas) e controlar o embarque/desembarque.
- Ações Rápidas: Oferece ações rápidas como otimizar a rota com IA e exibir avisos importantes.
- Acompanhamento em Tempo Real: Permite aos pais acompanhar o status do aluno e a localização da van escolar em tempo real.
- Ações e Comunicação (Pais): Permite aos pais comunicar ausência, gerenciar autorizados, enviar/receber mensagens e visualizar o financeiro.
- Controle de Embarque/Desembarque (Auxiliar): Permite ao auxiliar controlar o embarque/desembarque dos alunos para garantir a segurança.

## Style Guidelines:

- Cor primária: Azul dessaturado escuro (#30446b), evocando uma sensação de segurança.
- Cor de fundo: Azul dessaturado muito escuro (#141b26).
- Cor de destaque: Teal (#2ab0c1) para destacar alertas críticos e elementos interativos.
- Fonte do corpo e do título: 'Inter' (sans-serif) para uma leitura limpa no celular.
- Use ícones simples e claros para tipos de incidentes, status e alertas.
- Layout limpo, baseado em cartões para incidentes. Alto contraste e claramente rotulado.
- Transições e animações sutis para atualizações de mapas e notificações de alertas.
